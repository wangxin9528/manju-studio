# Changelog

## v0.1.0 — 2026-11-13

First public release.

- Local-first vertical motion-comic pipeline: script → storyboard → panels →
  TTS → procedural score/SFX → MP4 + SRT + cover.
- Built-in 8-shot director and five visual palettes.
- Editable storyboards and per-shot AI image prompts.
- Optional Ollama script rewrite with deterministic structure fallback.
- Optional ComfyUI + IP-Adapter character references for AI storyboard art.
- Local JSON project store, job progress UI, white-paper interface.
- Sample project 《雾城记忆》 and one-shot real ComfyUI test.
- Agent skill template.
- Optional installers for Ollama and ComfyUI; models are never bundled.
